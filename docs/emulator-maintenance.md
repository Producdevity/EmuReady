# Emulator maintenance

All new icons are transparent 500 × 500 WebP files in `public/assets/emulators`. No generative image tools were used. Icons are available in the admin logo picker after deployment; existing production records still need their logo selected. Seed data is maintained separately and is not run by deployment.

Processing: use foreground layers where available, remove transparent padding, preserve aspect ratio, fit inside 460 × 460 with 20 px transparent margins, encode WebP at quality 90 with alpha quality 100 and strip metadata. Bitmap sources are conventionally resampled; no AI upscaling is used. The WatermelonDS vector was converted directly from Android paths. ARMSX3's “3” and Fin's fin were manually masked from their original artwork. White/dark launcher backgrounds were removed from HakuX, BannerHub, touchHLE and Astris; app tiles were removed from Manic EMU, aX360e, idTech4A++ and PicPic. Manic EMU and aX360e use their original brand colors for the isolated marks. Pixel art uses nearest-neighbor scaling. Fritchii currently ships Lichii's icon; reuse `lichii.webp` instead of duplicating it.

Seed additions reflect production's NX, DroidDeck, ARMSX3 and touchHLE records, plus requested HakuX. Eden's system associations include both Switch generations, as in production. No migration or seed was executed.
